# Muse Skill Collection

293 publicly available agent skills, converted to Muse format and bundled into 10 group archives for free download. Each archive contains an INSTALL_FOR_MUSE.md manual and full attribution for every skill.

Download the archives from the Releases page. All credit for the skills belongs to their original authors; the collection claims only the selection, conversion, adaptation notes, and packaging.

License notes: most skills are MIT or Apache-2.0. Nine skills are CC-BY-SA-4.0 and one (arduino-maker) is AGPL-3.0; share-alike and copyleft terms apply to those. One skill, git-master, is under the Sustainable Use License 1.0 (non-commercial); its full license text is carried inside its archive. 51 skills had no license stated in their source repository (checked 2026-11-23) and are marked as such in the attribution files.
